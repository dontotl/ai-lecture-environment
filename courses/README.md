# 강의 모듈

각 강의는 `courses/<순번>-<주제>/`에 독립적으로 배치된다. 수강생은 모듈의 `README.md`를 읽고 `lab/`에서 실습하며 `checks/`의 검증 기준을 따른다.

| 순번 | 주제 | 상태 |
| --- | --- | --- |
| - | 준비 중 | - |

새 주제 구조는 `courses/_template/`을 복제하거나 다음 명령으로 만든다.

```sh
./scripts/new-course.sh --id 01 --slug oracle-basics --title "Oracle 기초"
```
