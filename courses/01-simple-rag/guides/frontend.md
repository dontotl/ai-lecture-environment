# 정적 프론트엔드 공통 가이드

`static/index.html`, `styles.css`, `app.js`를 사용하고 빌드 도구 없이 FastAPI에서 제공한다. 글·코드·버튼이 읽기 쉬운 한국어 교육 화면으로 만든다.

## 경로와 화면

- 브라우저 API 호출은 `/simple-rag/api/...`를 사용한다. `localhost:9000` 등 내부 포트나 루트 `/api/...`를 하드코딩하지 않는다.
- CSS/JS/iframe 자산은 `./styles.css`, `./app.js`, `./architecture/index.html`처럼 데모 루트 기준 상대 경로를 사용한다. 외부 CDN 없이 동작한다.
- 탭 5개는 키보드로 선택할 수 있고 활성 상태·패널 관계를 표시한다. 모바일에서는 탭 줄바꿈과 세로 스크롤을 허용한다.
- RAG 체험에 현재 실행 모드·검색 방식·로딩·오류·빈 결과를 표시한다. 질문 중에는 중복 요청을 막는다.
- 검색 근거에는 문서명, 조항, 본문, 점수를 표시한다. 생성 답변과 검색 원문을 시각적으로 구분한다.
- 코드 예제는 실제 생성된 코드와 일치하는 발췌본이다. API 키나 `.env`를 샘플로 공개하지 않는다.
- 사용자 입력, 문서, 답변은 `textContent` 등으로 렌더링한다. LLM 출력을 신뢰된 HTML로 삽입하지 않는다.

## 셀프 시연

예제 질문 버튼을 제공하되 유료 요청을 자동 실행하지 않는다. 질문을 채운 뒤 사용자가 검색 또는 답변 버튼으로 실행한다.

1. “교육비 지원 한도는?”으로 단일 근거 확인.
2. “재택근무 중 교육을 수강하면 어떤 규정이 적용돼?”로 문서 2개 비교.
3. “해외 지사 주차비는?”으로 문서에 없는 규정 확인.
4. 기술 샘플 탭에서 검색 함수 읽기.
5. 아키텍처 탭에서 질문이 이동하는 경로 확인.

화면 하단에 “모든 규정은 교육용 가상 자료”를 표시한다. 온라인 전환 시 전송 데이터와 API 비용 안내를 보여준다. 데모의 API 키를 브라우저에서 입력·보관하게 하지 않는다.
