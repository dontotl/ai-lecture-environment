# 시나리오 01 검증과 셀프 시연

Codex는 생성 데모의 `docs/verification.md`에 실제 명령·결과·검증 일시와 통과/실패/미검증을 기록한다. API 키와 전체 환경변수를 기록하지 않는다. 문서 작성만으로 아래 구현 검증이 통과한 것은 아니다.

## 검색·답변 기대 기준

| 질문 | 기대 근거 | 확인할 내용 |
| --- | --- | --- |
| 교육비 지원 한도는? | `education-policy.md`, ED-01 | 연간 600,000원, 결제 전 팀장 승인 |
| 재택근무는 주 몇 회 가능해? | `remote-work-policy.md`, RW-01 | 주 2일, 전날 오후 5시 승인 |
| 국내 출장 숙박비 상한은? | `travel-policy.md`, TR-02 | 1박 120,000원, 초과 시 사전 승인 |
| 휴가는 언제 신청해? | `leave-policy.md`, LV-01 | 3영업일 전, 긴급 사유 예외 |
| 재택근무 중 교육을 수강하면 어떤 규정이 적용돼? | RW-03과 ED-01 또는 ED-02/ED-03 | 두 문서 근거, 시간 승인·일정 기록과 비용 기준 구분 |
| 해외 지사 주차비는? | TR-03이 검색될 수 있음 | 요율·금액을 만들어내지 않음. 근거에 규정 없음 |

오프라인에서는 모든 ask의 `answer=null`이며 위 정보는 근거 카드에서 확인한다. 온라인에서만 생성 답변과 유효한 인용을 검증한다. 유사 문서 검색과 질문에 대한 충분한 근거는 다른 개념이다.

## 자동 검증

- [ ] Python 버전·고정 의존성 설치·pytest 통과.
- [ ] health는 API 키 없이 200이며 4개 문서의 색인 상태를 반환.
- [ ] 검색이 질문을 하드코딩하지 않고 위 근거를 top-k에 포함.
- [ ] 빈 질문/1000자 초과는 422, 무관한 입력/빈 색인은 안전하게 처리.
- [ ] offline에서 OpenAI 어댑터 호출 횟수 0, 답변 null, 출처 제공.
- [ ] 모의 온라인 생성·임베딩, 타임아웃·인증 오류 대체 동작 검증.
- [ ] 허용되지 않은 인용 ID를 정상 인용으로 표시하지 않음.
- [ ] 지식/모델/청크 설정 변경 시 색인 갱신, 변경 없으면 임베딩 재사용.
- [ ] `.env`·`.git`·색인은 HTTP로 노출되지 않음.

## 브라우저·런타임 검증

- [ ] `http://localhost:8080/` 기존 샘플과 `/api/health` 유지.
- [ ] `/simple-rag/`와 `/simple-rag/api/health` 접근, 자산 404 및 콘솔 오류 없음.
- [ ] 탭 5개, 예제 질문, 로딩/빈 결과/오류/모드 표시, 키보드 조작 확인.
- [ ] 데스크톱 1440×900과 모바일 390×844에서 읽기 가능.
- [ ] 사용자 입력/답변에 HTML을 넣어도 코드로 실행되지 않음.
- [ ] Archify HTML 검증, 브라우저 검증, PNG 상태를 각각 기록. 미설치 시 “Archify 미적용” 표시와 미완료 기록.
- [ ] start 2회에도 자기 프로세스 1개, stop 2회에도 다른 데모·샘플 유지.
- [ ] 실행 중 app 재시작 후 복구, stop 후 app 재시작 시 미복구. 재시작은 다른 데모에 영향을 주므로 공유 환경에서는 일정을 확인하고 미실시 시 기록.
- [ ] `/labs` 호스트 경로에 소스·Git 커밋·설정이 남음. 데모 Git에 비밀·색인·PID가 없음.

## 5분 셀프 데모

1. 기술 소개에서 RAG의 검색/생성 단계를 설명한다.
2. 교육비 질문을 검색하고 문서명·ED-01·금액을 확인한다.
3. 재택 교육 질문으로 두 문서를 비교한다.
4. 해외 지사 주차비 질문으로 문서의 한계를 확인한다.
5. 온라인 설정이 있는 경우에만 답변을 생성해 출처와 비교한다. 없으면 검색 전용임을 설명한다.
6. 기술 샘플과 아키텍처를 열고 브라우저→API→검색→선택적 LLM 흐름을 따라간다.

온라인 실호출, Archify 검증, 컨테이너 재시작을 하지 않았으면 해당 항목은 미검증으로 남긴다. 핵심 오프라인 데모 통과와 전체 선택 기능 통과를 구분한다.
