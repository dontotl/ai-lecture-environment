# 교육자 비공개 저장소 운영

수강생용 저장소는 Docker 환경과 공개 실습만 제공한다. 교육자는 별도의 비공개 저장소에서 강의 원고, 강사 노트, 모범 답안, 평가 기준, 교육자 전용 자동화 도구를 관리한다.

## 권장 구조

```text
ai-lecture-instructor/
├── course-skills/course-operations/
├── courses/<순번>-<주제>/{README.md,lab,solution,instructor,assets,checks}
└── scripts/
```

`course-operations`은 새 모듈 작성, 학습 목표 확인, 실습 검증, 수강생 배포 전 점검을 돕는 자체 제작 Codex 스킬이다. 제3자 스킬 실제 파일은 이 저장소에도 복사하거나 배포하지 않는다.

## 배포 흐름

1. 비공개 교육자 저장소에서 `lab/`, `solution/`, 강사 노트를 작성하고 검증한다.
2. 수강생에게 공개할 `README.md`, `lab/`, `assets/`, `checks/`만 선별한다.
3. 수강생 저장소의 `courses/<순번>-<주제>/`에 반영하고 독립 검증한다.
4. `solution/`과 `instructor/`는 비공개 저장소에 남긴다.

수강생 저장소의 환경 버전 또는 Git 태그를 교육자 모듈 README에 기록한다.
